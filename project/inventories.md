File upload: **not offered**. Secure storage and delivery are not implemented; the form says specifications can be sent by reply.

Server behaviour: JSON in, JSON out. `400 {fields}` for validation (client maps to fields), `429` rate limit (5 per 10 min per IP per instance), `503` when no delivery channel is configured, `502` when every channel fails (lead written to the log as `LEAD_UNDELIVERED`), `200 {ok:true}` on delivery. Client redirects to `/thank-you` only on `200 ok:true`.

## 8. Analytics event map (GA4 `G-LKWW9913VR`)

Loaded on every non-localhost host. Every hit carries `site_hostname`, `site_environment` (`production` for aragonitesand.com / www, otherwise `preview`), `page_path` and, on config, `form_version`. Visiting any URL with `?internal=1` sets a local flag that suppresses GA for that browser (developer exclusion). Add `?debug_events=1` to log events to the console.

| Event | Trigger | Parameters |
|---|---|---|
| `quote_start` | first focus inside the form, or click on any "Request a Quote" link (`data-event`) | `placement` |
| `quote_submit` | form passes client validation and is posted | `buyer_type`, `application`, `quantity` |
| `quote_success` | backend returns `ok:true` (before redirect to `/thank-you`) — the conversion | `buyer_type`, `application`, `quantity`, `request_type` |
| `quote_error` | client validation failure, server validation failure, or delivery failure | `error_type`, `field` / `message` |
| `sample_request` | sample CTA click, or success with sample = Yes | `placement` / `application` |
| `product_details_request` | product-details CTA click, or success with request type = Product details | `placement` / `application` |
| `specification_view` | page view of `/grades-and-specifications` | — |
| `packaging_view` | page view of `/packaging-and-delivery` | — |
| `technical_document_download` | click on any `.pdf` link | `document`, `placement` |
| `email_click` | any `mailto:` link | `placement` |
| `phone_click` | any `tel:` link | `placement` |
| `outbound_aragocor_click` | any link to aragocorminerals.com | `placement`, `link_url` |

Mark `quote_success` as the key event in GA4. Cross-domain: every AragoCor link carries `utm_source=aragonitesand.com&utm_medium=referral&utm_campaign=<page>`; if both sites share a GA4 property, add both domains to the property's cross-domain list (not verifiable from this session).
