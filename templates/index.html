Documentation

What ships with the order

Every shipment carries a certificate of analysis for the lot it came from, matched to the code printed on the pack. Source documentation is available for the carbonate bank the material comes from.

A lot lookup is not published on this site. Analyses are issued against the shipment they belong to, so a code on a bag is answered with the signed report for that lot rather than a page.
